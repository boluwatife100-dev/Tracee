## Environment Variables

Set `MONGODB_URI` in `.env.local` to a MongoDB connection string. The database is
selected from the URI, and onboarding preferences are stored in the `tracee`
collection. For a local MongoDB server, use:

```env
MONGODB_URI=mongodb://127.0.0.1:27017/tracee
```

Configure the same variable in your deployment environment. Do not commit
connection strings or credentials.

## User Model

The MongoDB user document is defined in [`models/User.ts`](models/User.ts) and
stored in the `tracee` collection. It is keyed by Clerk user ID and includes
account profile fields, preferences, and onboarding status. Passwords remain
managed by Clerk and are not stored in MongoDB.
